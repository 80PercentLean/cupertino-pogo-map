# Working With GeoJSON

[GeoJSON](https://geojson.org) is a format for encoding a variety of geographic data structures. It can represent things like points, paths, and areas on a map, along with additional information about each thing.

Because our map data is built with GeoJSON which is a widely supported open standard format, our data can be easily used with many other applications and tools.

All of our GeoJSON can be found in [`/src/geojson`](../src/geojson/) as `.geojson` files.

An easy way to work with them outside of this project is to import them at [www.geojson.io](https://geojson.io) where you can visualize them on a map, edit the data and see those changes reflected immediately, and more!

This was actually how we originally worked with the data as explained in our ["Motivation" document](./motivation.md).
